# v0.7.0
- Basic Info in the new look: job badge with your level, big HP and SP bars with numbers, exp bars, weight and zeny chips, and a compact small mode.
- The Basic Info menu opens from a handle, with the game's buttons on rounded tiles.
- Fixed: Basic Info now matches for every job, not only 4th class. The game swaps in a different window below 4th class, and only the 4th-class one was covered at first.
- Fixed: the compact Basic Info panel's level badge no longer gets clipped by the window's own edge.
- The NPC shop (buy and sell, including the merchant's buy/sell/cancel buttons) is in the new look.
- The FPS counter is bigger and its two readouts no longer fight for one line.
- Apply and Reset on the Skill Tree, and the npc shop's Buy/Sell/Cancel/OK, draw their own label as real text now instead of just a glow around the game's picture.
- Fixed: the Skill Tree's panel no longer covers the character pose the game draws behind it.
- Fixed: the remaining skill points counter uses gold instead of blue, for better contrast against the panel in light mode.
- The light/midnight toggle in the Inventory is now a sky-toned pill with both the sun and the moon always showing and a sliding knob, so the active theme is obvious from more than colour alone.
- New setting to keep the game's own Basic Info.

# v0.6.0
- Party and Friends, and Guild, in the same look as the Inventory.
- Every other game window gets the blue title bar, round close button, rounded frame and slim scrollbar.
- New setting to keep the game's own Party, Guild and other windows.

# v0.5.0
- The Inventory (Alt+E) is rebuilt in the item window's look: tabs on top, rounded slots, search, sort, list view, weight bar with zeny, hover label and resize grip.
- Equipment (Alt+Q), Status and Skill Tree (Alt+S) in the same look.
- Light and midnight themes for every window, switched from the Inventory.
- New settings to keep the game's own Inventory, Equipment and Status, or Skill Tree.
- The read-only server command is unchanged.

# v0.4.0
- New Your copies section: how many you carry, how many are equipped, bound state and whether they can be traded.
- New Restrictions section with the game's own move limits, always visible.
- Updates the read-only server command, so this version needs a game restart.
