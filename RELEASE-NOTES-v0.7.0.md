Basic Info now matches, the NPC shop and FPS counter get a skin of their own, and a round of fixes from an in-game audit.

- **Basic Info**: a job badge with your base level, big HP and SP bars (and AP at 4th class) with numbers in them, exp bars, weight and zeny chips, and the menu on rounded tiles. The compact mode (Alt+V) keeps it all legible without clipping. This now matches for every job, not only 4th class — the game uses a different window below 4th class, and the first pass only covered the one at 4th class.
- **The NPC shop** (buy and sell, including the Buy/Sell/Cancel/OK buttons): the matching title bar, panel and list rows.
- **The FPS counter**: enlarged and its two readouts no longer fight for one line.
- **Skill Tree**: Apply and Reset draw real text now, instead of just a glow around the game's picture. The panel no longer covers the character pose the game draws behind it. The remaining skill points use gold instead of blue, for contrast in light mode.
- **The light/midnight toggle**: a sky-toned pill with the sun and the moon always both showing and a sliding knob, so the active theme reads from more than colour.
- **New setting**: "New Basic Info window" keeps the game's own.
