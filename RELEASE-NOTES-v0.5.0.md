The game's own windows now match the item window.

- **Inventory (Alt+E)** is rebuilt: tabs on top, rounded slots, search, sort (Game order, Type, Name, Newest), a list view with names and weights, a weight bar with zeny, a hover label with name, count and weight, and a resize grip.
- **Equipment (Alt+Q)**, **Status** and **Skill Tree (Alt+S)** get the same look: pill tabs, rounded slots and cells, stat names as text and round + buttons.
- **Light or midnight**: the moon and sun button in the Inventory switches every window.
- Every click, drag and button still works as in the game. Each window can be switched back to the game's own in the mod's settings.
- The item window and the read-only server command are unchanged.
