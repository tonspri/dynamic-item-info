The chat box and the skill bar join the new look, the Escape and settings menus match, and a round of fixes from in-game screenshots.

- **The chat box**: glass that keeps gameplay visible, gold sender names (the rest of each line keeps the game's own channel colour), more line spacing and margin, and a corner grip to resize its width (360-900px). The game's own height resize, tabs, filters, commands and shortcuts work as before. Tab names no longer get cut off.
- **Light chat that reads**: near-opaque cream, with every message colour the game uses (party, guild, whispers, system, errors, broadcasts) swapped for a darker shade of the same channel. Midnight keeps the game's own colours on a navy that stays readable over bright maps.
- **The skill bar**: larger tiles around the same sharp icons, each slot's hotkey under it (your custom keys too), a row number on each row, and Rows 1-4 buttons. Drag-drop, hotkeys, cooldowns, item counts, close and resize work as before, and the row count is saved the game's own way.
- **Escape menu, shortcut keys and Graphics Settings**: every button reads as text, tabs are pills, and checkboxes, sliders and lists take the theme. Buttons other mods add to the Escape menu show their own name.
- **Fixed**: the NPC shop's panels were see-through in the midnight theme.
- **New settings**: "New chat box", "Chat box background (%)" and "New skill bar", each to keep the game's own.
